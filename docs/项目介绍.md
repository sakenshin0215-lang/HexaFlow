# HexaFlow 项目介绍

## 1. 项目定位

HexaFlow 是一个针对复杂网页流程的 AI 自动化引擎，目标是：
1. 在动态页面中稳定推进任务。
2. 失败时自动修复并可人工接管。
3. 把成功路径沉淀为可复用轨迹。

## 2. 四种执行模式

1. 动态任务（`main_ai.py`）
   - 基于 TaskSpec，由 Agent 决策下一步。
2. 示教录制（`main_record.py`）
   - 人工操作，系统记录可回放轨迹。
3. 轨迹回放（`main_replay.py`）
   - 按步骤执行轨迹，并在失败时触发修复。
4. 循环任务（`main_loop.py`）
   - 按区间循环执行，整轮成功才计次。

## 3. 浏览器模式

1. Playwright 常规启动
2. CDP 连接真实 Chrome（推荐）
   - 复用 profile、扩展、登录态、钱包态

## 4. 统一配置体系

默认配置文件：`workspace/config/runtime.json`

核心设计：
1. 运行参数集中管理（browser/ai/replay/loop/record）。
2. 双 Agent Profile：`agent_ollama`、`agent_openai`。
3. 通过 `agent_profile` 或 `AGENT_PROFILE` 选择生效模型。
4. 保留兼容覆盖：`AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL`。

## 5. 稳定性与恢复

1. 动作失败检测（timeout/intercepted/not visible/no_progress）
2. 页面守卫（Guard）防止跑偏
3. AI 修复 Agent（改 selector / 改动作 / 跳步 / 人工接管）
4. 运行状态与报告落盘（JSON + Markdown）

## 6. 数据目录

统一使用 `workspace/`：
1. `traces/`：轨迹
2. `task_specs/`：任务定义
3. `reports/`：报告
4. `screenshots/`：截图
5. `state/`：运行状态数据库

## 7. 适用场景

1. 多弹窗、多状态页面自动化
2. Web3 交易前置流程自动化
3. 长流程、可恢复、可复盘任务
