## 关键模块职责

1. `main_ai.py`
   - 动态任务入口（TaskSpec + Agent 决策）。
2. `main_record.py`
   - 人工录制入口。
3. `main_replay.py`
   - 轨迹回放入口。
4. `main_loop.py`
   - 循环任务入口。

## 配置入口

1. 统一配置加载：`hexaflow/tools/runtime_config.py`
2. 默认配置文件：`workspace/config/runtime.json`
3. Agent 选择：`agent_profile`（`ollama` / `openai`）
