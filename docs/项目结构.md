# HexaFlow 项目结构

```text
HexaFlow/
├── hexaflow/
│   ├── agents/
│   │   ├── planner.py               # Trace/Step 数据结构（含 loop/page-guard 字段）
│   │   └── react_agent.py           # AI 决策、手动动作分析、回放失败修复决策
│   ├── browser/
│   │   ├── cdp_runtime.py           # CDP 启动/连接真实 Chrome
│   │   ├── human_handoff.py         # 人工接管检测与提示
│   │   └── okx_cdp_flow.py          # OKX 相关示例流程（可选）
│   ├── core/
│   │   ├── engine.py                # 主引擎（动态执行/回放/循环/恢复）
│   │   ├── state_machine.py         # 运行状态机（SQLite）
│   │   ├── trace_recorder.py        # 录制器（支持 click/type + loop 标记）
│   │   ├── task_schema.py           # TaskSpec（含 failure/loop policy）
│   │   └── run_reporter.py          # 执行报告生成器（JSON/MD）
│   ├── tools/
│   │   ├── dom_parser.py            # DOM 快照与定位器辅助
│   │   └── popup_healer.py          # 弹窗自愈与缓存
│   └── memory/
│       └── local_db.py              # SQLite 连接封装
├── memory/
│   └── workspace/
│       ├── traces/                  # 录制轨迹
│       ├── reports/                 # 执行报告
│       ├── screenshots/             # 挂起现场截图
│       └── state/                   # runtime.db 状态库
├── docs/
│   ├── 项目介绍.md
│   └── 项目结构.md
├── main.py                          # 动态任务入口（TaskSpec）
├── main_record.py                   # 示教录制入口
├── main_replay.py                   # 回放入口
├── main_resume.py                   # 挂起恢复入口
├── main_loop.py                     # 循环任务入口
└── requirements.txt
```

---

## 关键入口说明

1. `main.py`
   - 用 TaskSpec 驱动动态自动化。
2. `main_record.py`
   - 人工示教录制（支持 `ls/le` 循环标记）。
3. `main_replay.py`
   - 读取 trace 回放（含多层恢复 + AI 修复）。
4. `main_resume.py`
   - 查看挂起任务并按 `run_id` 恢复。
5. `main_loop.py`
   - 按 `loop_policy` 执行循环区间。

---

## Trace 中的扩展字段

`FlowStep` 目前支持：
1. `is_optional`
2. `loop_marker` / `loop_name`
3. `guard_url_contains`
4. `on_mismatch_actions`
5. `guard_retry_limit`

这些字段由回放引擎直接识别并执行。
